Мощное десктопное приложение для работы с VPN подписками, конвертации конфигураций и тестирования качества серверов.

## ✨ Возможности

### 🔧 Конвертация конфигураций
- **VLESS → JSON** - Преобразование VLESS ссылок в структурированный JSON
- **JSON → VLESS** - Обратная конвертация JSON в VLESS ссылку
- **Подписка → VLESS** - Извлечение всех VLESS ссылок из подписки
- **Подписка → Сервера** - Детальный парсинг подписки с отображением всех серверов

### 🌐 Поддержка протоколов
- VLESS
- VMESS
- Trojan
- Hysteria2

### 📡 Тестирование качества
- Реальный пинг через прокси (GET запрос)
- Настраиваемые интервалы: 1, 2, 5, 10 минут
- Автоматическая сортировка по скорости
- Визуальные индикаторы:
  - 🟢 Отлично (< 100 мс)
  - 🟡 Хорошо (100-200 мс)
  - 🟠 Средне (200-300 мс)
  - 🔴 Плохо (> 300 мс)

### 📊 Аналитика
- Детальная статистика по серверам
- Графики производительности
- Рекомендации по использованию
- Расчет доступности серверов

### 📜 История операций
- Автоматическое сохранение всех действий
- Экспорт истории в JSON
- Удобный просмотр с фильтрацией

### 🎨 Интерфейс
- Современный светлый дизайн
- Интуитивно понятная навигация
- Адаптивная верстка
- Кнопки с эффектами при наведении

## 🛠️ Технологии

## 📦 Установка

### Клонирование репозитория
git clone https://github.com/m25shar-art/VPN-Configs-Tolls-Convert

cd VPN-Configs-Tolls-Convert

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python main.py

# Сборка EXE

pip install pyinstaller

pyinstaller --onefile --windowed --name="VPN_Configurator" main.py

# Использование
Парсинг подписки:

Вставьте URL подписки или Base64 строку

Выберите режим "Подписка → Сервера"

Нажмите "Выполнить"

# Тестирование:

После парсинга нажмите "📡 Проверить сервера"

Выберите интервал проверки

Дождитесь завершения

# Анализ:

Нажмите "🔍 Проверить качество"

Получите детальный отчет

Визуализация:

Нажмите "📊 Диаграмма"

Просмотрите графики производительности
